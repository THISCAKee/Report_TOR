# ประวัติรายวัน สถิติงาน และการดาวน์โหลด Word

## เป้าหมาย

เพิ่มความสามารถให้ผู้ใช้เห็นรายละเอียดของวันที่มีการบันทึก เลือกดาวน์โหลดเอกสาร Word ได้ทั้งรายวันและรายเดือน และดูจำนวนครั้งสะสมของแต่ละงานจากทุกวันที่มีข้อมูล โดยไม่เปลี่ยนฟอร์มบันทึกหรือรูปแบบเอกสาร Word เดิม

## ขอบเขตการทำงาน

- เพิ่มรายการประวัติรายวันจากข้อมูล `WorkLog` ที่โหลดอยู่ในระบบ โดยแต่ละวันแสดงวันที่ จำนวนรายการ และจำนวนไฟล์แนบ
- เมื่อเลือกวันที่จากประวัติ ให้ใช้ตารางรายละเอียดเดิมแสดงงานของวันนั้น
- เพิ่มปุ่มดาวน์โหลด Word รายวันและรายเดือน
  - รายวันใช้เฉพาะ log ของวันที่เลือก
  - รายเดือนใช้ log ทุกวันที่อยู่ในเดือนเดียวกับวันที่เลือก
- เพิ่มสถิตินับครั้งแยกตามงาน โดยรวมทุกวันที่มีข้อมูลในชุด `logs` ปัจจุบัน และเรียงจากจำนวนครั้งมากไปน้อย
- ใช้ `buildWordDocument` และ CSS/โครงสร้างเอกสารเดิม ไม่แก้รูปแบบตาราง Word เนื้อหา หัวกระดาษ หรือขนาดภาพ
- ไม่เปลี่ยนฟอร์มเพิ่ม/แก้ไข/ลบข้อมูล

## โครงสร้างการออกแบบ

เพิ่มฟังก์ชัน pure ใน `lib` สำหรับจัดกลุ่มประวัติรายวันและนับสถิติตาม `workloadId` เพื่อให้ทดสอบได้โดยไม่ต้องพึ่ง Supabase หรือ DOM ส่วน `app/page.tsx` จะคำนวณชุดข้อมูลรายวัน รายเดือน ประวัติ และสถิติจาก `logs` แล้วส่งให้ component แสดงผล

การดาวน์โหลดจะใช้ตัวช่วยเดียวกับปัจจุบัน ต่างกันเฉพาะชุด log ที่ส่งเข้า `ensureWordImageDimensions` และ `buildWordDocument` กับชื่อไฟล์ ส่วน `buildWordDocument` จะไม่ถูกเปลี่ยนแปลง

## การแสดงผลและการใช้งาน

- วางประวัติรายวันในพื้นที่เดียวกับการทบทวนข้อมูล เพื่อให้เลือกวันแล้วเห็นรายละเอียดต่อได้ทันที
- วางสถิติแยกเป็นส่วนสรุปที่อ่านง่าย โดยใช้ชื่องาน จำนวนครั้ง และวันที่พบข้อมูลล่าสุดเท่าที่มีในโมเดลปัจจุบัน
- ปุ่มดาวน์โหลดระบุช่วงเวลาให้ชัดเจน และ disabled เมื่อไม่มีข้อมูลในช่วงนั้น
- รองรับหน้าจอแคบด้วยการเลื่อนแนวนอนเฉพาะตารางที่จำเป็น และคงรูปแบบ visual language เดิมของระบบ

## การทดสอบและเกณฑ์ยอมรับ

- ฟังก์ชันจัดกลุ่มรายวันคืนวันที่ไม่ซ้ำ พร้อมจำนวน log และไฟล์แนบถูกต้อง
- ฟังก์ชันสถิตินับจำนวน log ต่อ `workloadId` ข้ามทุกวันที่มีข้อมูล และไม่รวมงานที่ไม่อยู่ในข้อมูล
- การเลือกวันยังกรองตารางรายละเอียดได้เหมือนเดิม
- ดาวน์โหลดรายวันส่งเฉพาะ log ของวันนั้น และรายเดือนส่งเฉพาะ log ในเดือนนั้น
- เอกสาร Word ใช้ฟังก์ชันและ markup เดิม รูปแบบเดิมไม่เปลี่ยน
- test, type-check และ production build ผ่าน
